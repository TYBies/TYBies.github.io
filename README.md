# Oluwatoyin Balogun — DevOps portfolio

A lightweight, responsive recruiter portfolio presenting professional experience, separate DataScientest bootcamp practice, and a selected document-processing prototype.

**Website:** https://tybies.github.io/

## Contents

- `index.html` — portfolio content and semantic navigation
- `styles.css` — responsive layout, keyboard focus and reduced-motion styles
- `script.js` — progressively enhanced mobile navigation
- `.nojekyll` — serve the static files directly

No build system or third-party runtime dependencies are required. Navigation remains available without JavaScript.

## Preview locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080/ and check desktop and mobile layouts.

## Deployment

GitHub Pages publishes the root of the `main` branch. Changes should be reviewed before a normal push; no generated output is required.

Professional experience and bootcamp training are described separately. The linked document-splitting project is a prototype, not a claim of independently verified accuracy or production readiness.

This repository contains only the public website. CV documents, direct email/phone details, internal audits and test reports are intentionally excluded.
